# Spartan Renovations Website (GitHub Pages Ready)

3-page website built for Spartan Renovations:
* `index.html` (Homepage)
* `services.html` (Services inventory)
* `contact.html` (Estimate request form & direct contact)
* `styles.css` (Accessible brand styling matching logo)
* `images/logo.png` (Transparent logo included and linked)
* `CNAME` (Custom domain config)

## Color Palette & WCAG Compliance
* **Spartan Blue:** `#1d4ed8` (WCAG AAA compliant with white text: 6.7:1 contrast ratio)
* **Navy / Black:** `#0f172a` (Headings and high-contrast elements: 17.8:1 contrast ratio)
* **Slate Gray Text:** `#1e293b` & `#475569` (Meets WCAG AA & AAA standards)
